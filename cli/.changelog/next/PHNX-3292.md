- **`sessions resume`/`sessions attach`/`sessions focus` attach the first unique live tmux pane without waiting out the fleet (PHNX-3292).** First unique match wins: a selector naming a live pane on THIS box — the full `ag-<agent>-<8hex>` alias `agents tmux ls` prints, or its bare 8-hex suffix when it names exactly one live local pane — attaches with zero SSH. A local miss races `agents tmux list --json` across the fleet with RUSH-2203's `earlyExit`: the first reachable unique live pane attaches immediately and aborts remaining SSH, so an offline peer cannot stall a hit already in hand (~2 minutes of `unreachable or no agents CLI — skipped` was the measured bug). `--device` skips the local gate and is the only dial on both the live-tmux race and the index fallback. Two LIVE panes (local or fleet-answered) sharing the same 8-hex suffix fail closed with both `device:name`; a dead/retained pane is never attached. Source: `cli/src/lib/session/local-tmux-attach.ts`, `cli/src/lib/session/fleet-tmux-attach.ts`, `cli/src/commands/{sessions,sessions-resume,attach,focus,resume}.ts`.
