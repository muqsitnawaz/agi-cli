- **fix: `agents sync <agent>` self-heals a `~/.<agent>` symlink left pointing at an uninstalled version (RUSH-2471).** `removeVersion` clears the config symlink only when it removes the symlinked version, so a version-home whose launch binary vanished by any other route — grok self-updating its per-version binary out from under the old dir, a manual delete, a half-finished install that seeded the home but never landed the binary — left `~/.<agent>` resolving to a dead version while every resource sync landed in an installed one (observed on yosemite-s0: `~/.grok -> grok/1.0.0` while only 0.2.82 / 0.2.91 were installed). `agents sync <agent>` now repoints such a dangling symlink at the resolved default (or the newest installed version) before syncing, so the conventional-path home and the installed set can never diverge. A symlink already pointing at an installed version (a deliberate `agents use` choice), a real config directory, and isolated-only agents are all left untouched. Source: `apps/cli/src/lib/versions.ts`, `apps/cli/src/commands/sync.ts`.
