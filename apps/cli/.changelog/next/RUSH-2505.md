- **In-place YAML writers no longer churn synced config, which silently blocked fleet pulls (RUSH-2505).**
  `agents.yaml` had five in-place writers that did not agree on the bytes they emit: `state.ts` and
  `manifest.ts` forced block style, while `feed.ts`, `activity.ts` and `migrate.ts` took the emitter
  defaults. The same key flip-flopped depending on which command last touched the file
  (`mcp: {}` against `mcp:` + an indented `{}`), and the default emitter also pads flow collections,
  rewriting `command: [agents, notify, "{message}"]` as `command: [ agents, notify, "{message}" ]`.
  Both diffs are semantically no-ops, which is what made them dangerous: the working tree went
  permanently dirty, `agents repo pull` then refused with "Blocked by local changes" and
  `git merge --ff-only` refused, so the box stopped receiving fleet config with nothing reporting it —
  seven boxes fell 37-52 commits behind. All five writers now serialize through one canonical
  `stringifyDoc()`, verified to round-trip the real committed `agents.yaml` byte-for-byte.
  Source: `apps/cli/src/lib/yaml-io.ts`.
