- **Inspect Watchdog decisions and actions from the CLI (RUSH-2410).** `agents watchdog history [sessionId]` renders persisted decisions, nudges, rotates, and errors newest-first, with duration/limit filters, optional heartbeat ticks, and safe JSON that excludes transcript content. Persisted transcript context is capped at 4,096 characters per event so it cannot crowd decision history out of the retained audit window. `agents watchdog status` points to the history command instead of leaving the audit log undiscoverable. Source: `apps/cli/src/commands/watchdog.ts`, `apps/cli/src/lib/watchdog/{log,history}.ts`.
