- **The `pi` (Oh My Pi / `omp`) harness now declares `interactiveRepl`, restoring it as a candidate for prompt-less `agents run auto`.** The `pi` harness (added concurrently with the `interactiveRepl` capability, RUSH-2185) shipped without the field, which failed the capability-completeness test on `main` and, once fixed, would otherwise have excluded `omp` from prompt-less interactive auto-picks. `omp` is a terminal-first, session-based coding agent whose bare invocation opens a REPL, so it is marked `interactiveRepl: true`. Source: `apps/cli/src/lib/agents.ts`.
