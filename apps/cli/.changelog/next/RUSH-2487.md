- **A project definition can bind several local directories, each with its own GitHub remote, resolved by one shared list (RUSH-2487, spine track).** `agents projects add <name> --dir <path...>` and `agents projects set <name> --add-dir <path...>` / `--rm-dir <path...>` bind (and unbind) additional local repo directories in `repos[]`. Each `--dir`/`--add-dir` names a **local directory**; its `owner/repo` slug is read by running `git remote get-url origin` **inside that directory** and normalizing it — never inferred from the directory path, because the checkout dir and its GitHub owner routinely differ (`~/src/github.com/muqsitnawaz/agents-cli` vs the `phnx-labs/agents-cli` remote). A directory with no `origin` takes an explicit `--slug owner/repo`, else the command errors; paths are stored home-relative. `--rm-dir` matches on the same resolved absolute path the add side stores, so a trailing slash or a shell-expanded form still unbinds the right entry, and a value matching no bound dir exits 1 with the bound list instead of printing `Updated <name>` over a no-op. One resolver, `projectDirsAbs(def, { forRemote, checkoutRoots })` (`apps/cli/src/lib/projects.ts`), is the single source of a project's ordered directory list in two shapes: the working dirs a spawn grants (primary `defaultPath ?? root` first, then each `repos[].path` joined with `repos[].subpath`), or — with `checkoutRoots` — the enclosing git checkout roots (`root`, each `repos[].path`, no subdir/subpath) that the workspace probe (`workspaceTargetsForDef`) needs so it resolves `.git` at a real repo root, never a monorepo subdir. Both are deduped; local drops non-existent dirs, remote keeps every home-relative entry. The stale `agents projects` help note now points at `agents repo push user` (`agents push` was removed). The spawn-side consumers of this resolver — `agents run --project` / `agents teams create --project` folding the bound dirs into each harness's directory grants (Claude via native `--add-dir`, `apps/cli/src/lib/exec.ts:1269`; Codex into its edit profile's `workspace_roots`, `apps/cli/src/lib/exec.ts:1133`; dropped for other harnesses) and the AGI EXT/VS Codium extension — land in the companion RUSH-2487 tracks.
