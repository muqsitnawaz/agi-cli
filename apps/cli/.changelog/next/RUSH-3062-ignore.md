- **Dismissing a discovered device now syncs fleet-wide: the ignore-list moved into tracked `agents.yaml` (RUSH-3062).** `agents devices ignore <name>` used to record the dismissal in `~/.agents/.history/devices/ignored.json` — a gitignored, per-machine path — so the node kept re-surfacing as a discovery suggestion on every other machine. The store is now the central, tracked `~/.agents/agents.yaml` under `fleet.ignored`, a list of `{ name, ignoredAt, ignoredOn }` entries (who dismissed the node, when, and on which machine — the data behind the upcoming `agents devices ignored` list). Writes go through the same `withMetaLock` + atomic-write path as every central-config change, and a malformed `fleet.ignored` block is a hard error, never a silently-empty set. A one-shot migration in `lib/devices/config-migration.ts` unions any legacy `ignored.json` into `fleet.ignored` (central wins a name conflict) and removes the legacy file only after the write lands; `agents fleet capture` carries the list forward instead of dropping it. Source: `apps/cli/src/lib/devices/registry.ts`, `apps/cli/src/lib/devices/config-migration.ts`, `apps/cli/src/lib/fleet/types.ts`, `apps/cli/src/lib/fleet/capture.ts`.
