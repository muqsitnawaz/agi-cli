- **`agents fleet capture` no longer drops `fleet.ignored` (RUSH-3062).** `captureFleet` rebuilt the manifest from live state and carried forward only `discovery`/`secrets`/`routines`/`defaults` — a capture on any box would have wiped the synced dismissal list and pushed that deletion fleet-wide. The ignore-list now carries forward verbatim, pinned by a test. Also: the `agents-yaml` JSON schema documents the `fleet.ignored` entries, and the `browser/profiles.test.ts` state mock exports `getDevicesIgnoredPath` so the device-config migration stops logging a spurious failure there. Source: `apps/cli/src/lib/fleet/capture.ts`, `apps/cli/schema/agents-yaml.schema.json`.
