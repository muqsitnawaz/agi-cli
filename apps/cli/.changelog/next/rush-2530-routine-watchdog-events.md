- **Daemon routines and watchdog emit first-class events.** Scheduler fires write `routine.start` / `routine.end` (including spawn failures) and each watchdog pass writes `watchdog.action` with live/stalled/nudged counts onto the unified stream — filterable via `agents events --module routine|watchdog` or `--event routine.start`. Daemon process lifecycle remains the existing log mirror (`daemon.start`/`stop`/`error`/`info`). Source: `apps/cli/src/lib/daemon.ts`, `events.ts`.
