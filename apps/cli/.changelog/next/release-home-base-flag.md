- **`scripts/release.sh --home-base <host>` releases from a different Mac when the default sign host is unreachable.** The build/sign/notarize/npm-publish phase was pinned to a single hardcoded constant (`RELEASE_HOME_BASE="mac-mini"`), so a release was impossible whenever that box was asleep, offline, or rebuilt — the publish is the last phase, so the run would merge and tag before dying at the ssh hop. `mac-mini` stays the default and releasing stays zero-config; the new flag is an explicit per-invocation override, deliberately not an env var or config key, so the box that signed a release is visible in the command that made it rather than ambient state. An overridden host is probed for reachability and macOS **before** the first mutation and refuses loudly otherwise, and the resolved name rides along to the remote `--home-base-phase` so its errors name the box actually running. Also fixes `release-worktree.sh` picking the flag's value as the release version (`--home-base zion` named the worktree "zion"). Source: `apps/cli/scripts/release.sh`, `apps/cli/scripts/release-worktree.sh`, `apps/cli/scripts/release.test.ts`.
