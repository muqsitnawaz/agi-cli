- **`agents view <agent>` no longer triggers an implicit resource-drift scan or sync prompt (issue #2058).** Bare `agents view claude` now exits after printing the installed-version inventory. The drift calculation and interactive "New resources available?" prompt that previously ran at the end of every bare-agent view are removed. Explicit detail surfaces — `view <agent>@<version>`, section flags (`--skills`, `--hooks`, etc.), `--merged`, and `--json --resources` — are unaffected. Source: `apps/cli/src/commands/view.ts`.

- **`agents doctor <agent>@<qualifier>` accepts symbolic qualifiers via the shared agent-spec resolver (issue #2058).** The private literal-version parser in `doctor.ts` is replaced with `resolveAgentTargets` from `lib/agent-spec`, so `@latest`, `@oldest`, `@default`, `@pinned`, and `@all` all resolve correctly. Bare `agents doctor <agent>` (no qualifier) continues to sweep every installed version with a non-isolated fix path; all explicit qualifiers (including `@all`) set `versionExplicit: true` and scope `--fix` to the resolved version set. `--device` forwarding is unchanged — the qualifier passes through `stripRoutingFlags` without modification. Source: `apps/cli/src/commands/doctor.ts`, `apps/cli/src/commands/doctor.test.ts`, `apps/cli/src/commands/view.resources.test.ts`.
