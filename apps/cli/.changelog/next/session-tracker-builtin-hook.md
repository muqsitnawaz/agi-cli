- **The session-tracker SessionStart hook now registers on every launch path via `agents sync`, and its state dir prunes itself.** `AGENT_SESSION_ID` has exactly one writer, `buildExecEnv` (`apps/cli/src/lib/exec.ts`), which runs only under `agents run` — a directly-launched `claude`/`codex`/`kimi` never got a `~/.agents/.cache/terminals/sessions/<pid>.json`, so every live-session consumer (AGI EXT, `sessions --active` pid reconciliation, the browser task reaper's session-dead fast path) was blind to bare launches. The `@agents/session-tracker` hook (`packages/session-tracker/src/hook.sh`) now ships inside the CLI package (`dist/lib/session-tracker-hook.sh`) and registers as a built-in manifest hook: `parseHookManifest` seeds a base-layer `session-tracker` entry whose script is materialized (write-if-changed, 0755) into the managed `~/.agents/.cache/shims/builtin-hooks/` dir, so the ordinary `agents sync` registration path wires it into every hooks-capable harness × version and `agents doctor`'s wiring inspector enforces it. Manifest hook commands carry no arguments, so the script self-identifies the harness from its parent process; a user can disable it with `session-tracker: { enabled: false }` in the user `agents.yaml` `hooks:` section. Out of the hook's reach, deliberately: gemini (hard-deprecated) and antigravity (its native config has no SessionStart event). The state dir also stops rotting: the hook prunes dead-pid state files (ESRCH only) and hour-old atomic-write temps after each successful write, a zero-byte temp is never promoted to a state file, an EXIT trap removes a temp stranded by a failed writer, and `writeStateAtomic`/`pruneStaleSessionState` (`packages/session-tracker/src/state-file.ts`, `src/reader.ts`) gained the same cleanup (measured on one machine before the fix: 1,456 unpruned state files, 20 orphaned temps, 17 zero-byte files). Source: `apps/cli/src/lib/hooks.ts` (`builtinHookManifest`, `BUILTIN_HOOK_NAMES`), `apps/cli/package.json` (build copy + files allowlist), `packages/session-tracker/src/hook.sh`.
